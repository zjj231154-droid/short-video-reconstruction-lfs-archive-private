# 《Walulu 异界游》项目规则

## 主要角色

本项目有两位不可被静默替换、重设或降格为配角的主要角色：

- 瓦露露（Walulu），白色幼猫。
- 黑猫侠客，正式姓名待定。

生成或编辑包含任一主角的图片、分镜、动画、视频、海报或商品视觉前，必须读取对应的 `assets/characters/<id>/character-profile.md`，并加载 `turnaround/three-view.png` 作为视觉参考。两位角色同框时必须同时加载两套资产。

## 恒定语气强制规则

任何类型的提示词只要出现对应角色，就必须原样加入以下恒定语气提示词。不得缩写、同义改写或用当前情绪覆盖基础声线。

### 瓦露露

```text
【瓦露露恒定语气】奶声奶气的小女孩声线，音色软糯清甜、稚嫩明亮，音高偏高，语速稍快但吐字清楚，带轻微软萌鼻音，句尾自然上扬；情绪真诚灵动，紧张时声音轻轻发颤，开心时轻快跳跃，生气时仍保留幼态可爱；不得使用成年女声、成熟御姐音、播音腔、尖锐喊叫或过度嗲腻的夹子音。
```

### 黑猫侠客

```text
【黑猫侠客恒定语气】清冷沉稳的少女声线，音色清亮柔和并带轻微磁性，音高为自然中音，语速从容，咬字利落，句尾收得干净；平时克制冷静，战斗时坚定有力，关心瓦露露时语气自然放软但不撒娇；不得使用幼童音、成熟御姐音、沙哑男声、播音腔或过度甜腻的语气。
```

两位主角同时出现时，以上两段均须加入。推荐拼接顺序：角色视觉描述 → 恒定语气提示词 → 当前情绪与动作 → 台词原文 → 音乐与音效。
