本文件中的文案是项目级强制常量。编写图片、分镜、动画、视频、对白、配音或声音生成提示词时，只要对应角色出现，就必须原样加入其恒定语气提示词。

## 瓦露露恒定语气提示词

```text
【瓦露露恒定语气】奶声奶气的小女孩声线，音色软糯清甜、稚嫩明亮，音高偏高，语速稍快但吐字清楚，带轻微软萌鼻音，句尾自然上扬；情绪真诚灵动，紧张时声音轻轻发颤，开心时轻快跳跃，生气时仍保留幼态可爱；不得使用成年女声、成熟御姐音、播音腔、尖锐喊叫或过度嗲腻的夹子音。
```

## 强制拼接规则

- 只有瓦露露出现：加入瓦露露语气提示词。
- 只有黑猫侠客出现：加入黑猫侠客语气提示词。
- 两位主角同框：依次加入瓦露露、黑猫侠客两段语气提示词。
- 推荐顺序：角色视觉描述 → 恒定语气提示词 → 当前情绪/动作 → 台词原文 → 音乐与音效。
- 当前情绪只能调整强弱、速度与停顿，不能覆盖恒定声线。
