# 第3段：能量碰撞与爆烟

## 制作参数

- 模型：可灵 3.0，首尾帧生视频
- 时长：8 秒
- 画幅：16:9 横屏
- 首帧：`start-frame.png`
- 尾帧：`end-frame.png`
- 节奏：立即碰撞 → 蓝球本体爆炸 → 烟雾向四周散开 → 冲击把两人推向两侧
- 基调：快速、夸张、搞怪，无伤害

## 可直接复制的视频提示词

使用已上传的首帧和尾帧生成8秒、16:9的快速微缩软陶动画短片。首帧是咕咕嘎嘎在左侧推着蓝色能量球、DORO在右侧用实体银色忍者飞镖迎击；核心事件必须清楚表现为：飞镖碰到蓝色能量球 → 蓝球本体从中心直接爆炸 → 白色烟雾从爆点快速向四周散开 → 爆炸冲击把咕咕嘎嘎推向左侧、把DORO推向右侧。尾帧是中央白色棉花状烟团完全展开，两位角色分别后仰停在左右两侧。两人始终站在同一张图书馆木桌上，左右位置固定，不能互换、瞬移、换脸或换装。开场立即发生碰撞，不要静止蓄力，不要一开始就出现尾帧烟团。

**0.0—0.7秒｜飞镖立即碰到蓝球**  
保持首帧的桌面侧面中广景。咕咕嘎嘎双翼继续向前推球，身体再压低一点，左脚蹬住桌面；DORO向前跨出半步，右翼握住实体飞镖向前短促刺出。蓝球向右移动，飞镖尖端向左移动，两者在画面中央迅速靠近。摄影机沿桌面轴线快速推近碰撞点，角色必须有明确的脚步承重、身体前倾和衣摆惯性，不能滑行。

**0.7—1.3秒｜碰撞点特写，蓝球即将爆裂**  
切到蓝球表面与飞镖尖端的极近特写。实心银色三角刀刃、短黑色握柄和尾端小圆环结构保持正确；飞镖尖端刚刚触碰蓝球表面，接触点立刻出现一颗刺眼的蓝白亮点。亮点在半秒内迅速扩散，蓝球表面从中心向外亮起几道短促发光裂纹，整颗球只鼓胀一次，马上进入爆炸，不要反复挤压、弹动或果冻变形。不要出现螺旋图案、闪电、火焰、知名动漫符号或文字。

**1.3—2.1秒｜蓝色能量球本体爆炸**  
蓝球内部蓝白亮点骤然膨胀，整颗蓝球从中心向外直接爆开，球形轮廓在一次强烈蓝白闪光中迅速瓦解。爆炸不是火球：没有红橙火焰、没有硬质碎片，蓝球只分解成柔和蓝光、少量发光颗粒和一圈透明空气冲击环。摄影机从碰撞点快速拉回到两人同框，并随爆炸短促震动一次。爆炸动作必须清晰完整，不能让蓝球只是慢慢消失或变成烟雾。

**2.1—3.7秒｜白色烟雾从爆点向四周散开**  
蓝球爆裂后，碰撞中心立刻喷出一团白色软烟。烟雾先从中心向左右两侧横向喷开，再向上和桌面方向扩散，连续鼓出许多圆润棉花球状烟块；几道细长烟流越过两位角色身前，随后汇成中央的大烟团。烟雾必须明显具有“从蓝球爆点向外散开”的方向和速度，不能凭空整团出现，也不能只原地缓慢变大。烟中保留极少量蓝色残光和几个向外飞散的小烟圈，没有火焰、黑烟或碎片。

**3.7—5.5秒｜爆炸冲击把角色对开**  
紧跟烟雾外扩，爆点的冲击波同时向左右两侧猛推。左侧咕咕嘎嘎先被风压顶住胸口，双翼被弹回脸前，双脚在桌面向左连续退两步，第二步失去一点平衡，身体向左后方明显倾斜；右侧DORO被反方向冲击推开，右翼连同飞镖被弹向上方，双脚向右连续退两步，左翼张开保持平衡，圆胖身体向右后方仰倒但没有摔下。两人必须从中央同时向相反方向移动，距离明显拉开，不能只在原地摆动。飞镖始终握在DORO右翼中，不能脱手、消失或变形。两人同时闭紧眼睛、鼓起脸颊，头发、外套边缘、蝴蝶结和白色飘带被冲击风吹向外侧。不得受伤、流血或掉下桌面。

**5.5—6.8秒｜散开的烟雾汇成中央烟团**  
向四周喷开的白烟在中心继续翻滚叠加，形成尾帧中的大型圆滚滚棉花状烟云；外圈小烟团和小烟圈因为惯性继续向上、向左右飘散，蓝色残光迅速减弱。摄影机保持横向全景并轻微后退，确保中央烟团与被推开的两个角色完整同框；烟不能盖住两位角色的脸和头部识别特征。

**6.8—8.0秒｜冲击结束并贴合尾帧**  
中央烟团继续缓慢翻滚两次后趋于稳定，小烟圈向上飘出。咕咕嘎嘎停在左侧后仰姿势，双翼交叉挡在脸前，巨型金属拉链、黄色鸟喙、发夹和黄色脚掌清晰；DORO停在右侧后仰姿势，紫色蝴蝶结与白色飘带仍随惯性轻摆，右翼握着尖端朝上的实体飞镖。摄影机停止震动并准确贴合尾帧的角色位置、烟团体积、桌面透视和暖光。最后0.3秒保持喜剧式定格，不让烟雾消散，不继续爆炸。

全程保持精品微缩手办电影质感、哑光软陶／黏土材质、温暖图书馆自然光和浅景深。DORO始终保持雪白圆胖企鹅身体、粉色螺旋发髻、紫色蝴蝶结、白色飘带、紫色大眼睛和黑红忍者短外套；咕咕嘎嘎始终保持黑色企鹅头套、白色眼部标记、黄色鸟喙、黑色短发、金属发夹、灰蓝眼睛、巨型金属拉链、黑白企鹅身体、黄色脚掌和白色火焰边忍者外套。

**禁止项：**开场静止、开场直接出现大烟团、蓝球缓慢消失、蓝球反复果冻弹动、烟雾凭空整体出现、角色只原地摇晃而没有被对向推开、角色换脸、左右位置互换、服装互换、发色改变、配饰消失、拉链缩小、鸟喙消失、角色变瘦、变成人类体型、长出人类手指、重复肢体、飞镖脱手、飞镖消失或变成护额徽章、蓝球穿过角色、脚底滑行、瞬移、穿模、溶解转场、背景重构、火焰爆炸、橙色火球、黑烟、木桌破损、角色受伤、流血、烧焦、文字、字幕、水印或平台界面。

**声音：**开场持续增强的能量低鸣，飞镖碰到蓝球时一声清脆金属轻响，蓝球本体爆炸时一声短促有弹性的“砰”，紧接着是向四周扩散的低频空气冲击声；烟雾散开时连续出现柔软的“噗、噗、噗”声，两位角色被推开时有衣料拍动声和四次快速脚掌踏木、摩擦木桌声，小烟圈飘出时有轻微泄气声；不要对白，不要旁白，不要音乐，不要字幕。
