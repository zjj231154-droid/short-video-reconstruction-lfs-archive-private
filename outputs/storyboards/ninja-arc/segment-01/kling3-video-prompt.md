# 第1段：飞镖挑衅

## 导演镜头

△ 约 8 秒，16:9，冲突前置的快速剪辑。小企背对镜头压在前景，粉粉在长桌远端突然从斗篷内侧甩出一枚银色三角训练飞镖 → 飞镖旋转擦过小企头套并钉入桌面 → 快切粉粉愤怒面部特写 → 反打小企由错愕转怒的面部特写 → 回到桌面轴线，粉粉连续迈出两步企鹅步，镜头同步快速推近 → 粉粉急停、双翅张开完成叫阵。

## 可灵3.0首尾帧视频提示词

使用已上传的首帧和尾帧，生成约 8 秒、16:9 的快速叙事片段。严格保持两位原创角色的外形、服装、比例、材质以及图书馆长桌环境一致；允许按照以下时间顺序做清晰硬切，但每次切换都必须保持人物位置、光线方向和桌面空间连续，最后准确落到尾帧。

0.0–1.3 秒，保持首帧的桌面过肩全景。画面开始后立即产生动作，不要静止等待。粉粉的右侧小翅膀迅速探入黑色斗篷内侧，抽出一枚小巧、钝头、无标志的银灰色三角训练飞镖；她压低重心，身体向左拧半圈，借回弹力量猛地向前甩翅，将飞镖贴着桌面方向掷向小企。动作必须由肩身扭转带动，不要长出人类手指。

1.3–2.2 秒，硬切飞镖侧面运动特写。镜头贴着木桌短距离跟随，银色飞镖快速旋转，带短促空气尾流，从小企毛绒头套侧边安全擦过；小企本能缩头，头套绒毛被气流轻轻带动。飞镖随后斜插进小企脚边的木桌表面并震颤两下，只制造挑衅，不击中任何角色，不流血、不受伤。

2.2–3.3 秒，硬切粉粉面部大特写。粉粉的紫色眼睛紧盯小企，眉毛明显下压，嘴角由平静收成倔强小怒嘴；粉色刘海落回额前，黑色护额、螺旋发髻和紫色蝴蝶结保持完整。镜头轻微推近，突出“就是我扔的”的挑衅感。

3.3–4.4 秒，反打小企面部大特写。小企先因飞镖擦过而睁大灰蓝眼睛、短促眨眼，随后迅速眯眼皱眉，脸颊微红，嘴角绷紧；黑色毛绒企鹅头套、黄色鸟喙、白色绒面额片、黑色短发和银色发夹保持一致。镜头轻微前冲后停住，表现她从错愕到被激怒的清楚表情变化，颈部没有项链。

4.4–7.2 秒，硬切回原桌面轴线。粉粉立即沿木桌朝镜头迈出两步短促而有力的企鹅步；每一步都有清楚的身体上下起伏和轻微左右摆动，脚掌真实接触桌面，不能滑行或瞬移。摄影机从小企背后的过肩全景快速、平稳地向粉粉推进，速度由慢到快。镜头前进时，小企的黑色毛绒头套和白色火焰羽织背影自然向左侧滑出画面，不转身、不抢主体。图书馆书架与木桌产生自然视差，景深逐渐变浅。粉色刘海、螺旋发髻、紫色蝴蝶结、白色飘带和斗篷下摆因惯性向后摆动，红色内衬短暂翻起。

7.2–8.0 秒，粉粉完成第二步，一只脚稳稳踏住桌面，身体猛地前倾，双翅快速甩向两侧并定住；斗篷和飘带继续摆动半拍后自然落下。她以愤怒、认真又带一点可爱笨拙的表情直视小企，动作减速后准确贴合尾帧构图，不回弹、不改变站位。

全程保持精品微缩手办电影质感、温暖自然图书馆光线和浅景深。粉粉保持雪白圆胖企鹅身体、粉色螺旋发髻、紫色蝴蝶结与白色飘带、紫色大眼睛、黑红短斗篷；小企保持黑白企鹅身体、毛绒企鹅头套、白色火焰羽织和背部“十代”。禁止角色变形、变瘦、长出人类四肢或手指、服装改变、配饰消失、面部漂移、脚底滑行、瞬移、穿模、重复肢体、溶解转场、变形转场、背景重构、烟雾、蓝色能量球、额外武器、飞镖击中角色、流血、字幕、水印和界面元素。

【声音】飞镖出手时短促的金属弹响和破空声，擦过头套时轻微绒毛气流声，飞镖钉入木桌时清脆“笃”声并伴随两次细小金属震颤声，随后是两次清晰的软脚掌踏木桌声、衣料摩擦声、飘带摆动声和镜头推进的短促空气声；不要对白，不要旁白，不要音乐，不要字幕。
