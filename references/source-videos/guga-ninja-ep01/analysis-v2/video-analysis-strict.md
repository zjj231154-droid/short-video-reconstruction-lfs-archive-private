## 节奏与声音观察

- 正片约 22.233 秒内包含约 16 个剪辑镜头，平均镜头长度约 **1.39 秒**。
- 情绪正反打通常保持在 **0.6–1.27 秒**；忍术生成过程允许放长到 **1.87–2.80 秒**；爆炸、摔倒、真人手等笑点在 **0.23–1.77 秒**内完成。
- 音轨显著能量峰值集中在 `0.70、1.00、2.60、4.40、5.95、6.85、7.75、9.25、11.35、13.25、17.10、19.10、20.95、21.25、21.80秒`附近，基本对应亮相、嘴型重音、球体膨胀、烟尘爆发、摔倒、砂／水生成和真人手进入。
- `20.206–20.721秒`存在约0.515秒短静默，为真人手反转前留出空拍；`22.233秒`以后进入尾卡，音轨明显停止或只保留平台提示音。
- 节奏核心不是“每5秒一个连续动作”，而是：**短反应镜头 → 稍长蓄力 → 极短接触 → 反差结果 → 表情奖励**。

## 对后续可灵 3.0 制作的影响

### 必须改变

1. 每张新分镜统一改为 16:9 横屏，优先 1280×720 或 1920×1080。
2. 不再把整段5秒剧情压进一组首尾帧；一组首尾帧只负责一个连续机位和一个主要动作。
3. 要严格复刻原片剪辑节奏，应按约16个镜头分别生成，再在剪辑软件中裁切到上表时长。
4. 若可灵单次最低只能生成5秒，则生成后必须裁切／变速：表情镜头保留0.6–1.3秒，忍术生成保留1.8–2.8秒，真人手反转只保留约1.4秒。
5. 不直接复制原片人物面部和知名忍者元素；两位主角继续以项目权威三视图与忍者篇服装图为身份依据。

### 推荐的新制作单元

- 严格复刻版：16组短镜头首尾帧，分别生成并后期裁切。
- 降本版：至少10组，允许把同机位内的连续动作合并，但不能把正反打和全景爆点放在同一次首尾帧插值中。
- 不推荐：继续使用旧版5组竖屏首尾帧方案。它会丢失近景正反打、闪切和反转速度。
