# 动作硬切时间轴提示词风格

本风格用于咕咕嘎嘎与 DORO 的动作段、对峙段、喊话段和视觉特效段。后续优化视频提示词时，优先参考这种写法，而不是只写“角色移动到尾帧”。

## 核心结构

按秒拆段，每段只描述一组可见动作：

```text
0-1.5s｜镜头类型，主动作：角色发力起势 → 道具脱手 → 道具飞行特效 → 对手躲避 → 落地卸力 → 定住。

1.5-3s｜硬切剪辑，角色A脸部近景特写，表情变化与台词；硬切角色B脸部近景特写，表情变化与台词。严格一人一句交替。

3-4.5s｜继续硬切近景，情绪升级，台词交替，镜头节奏更快。

4.5-6s｜切回双人全景，两人进入对峙姿态，身体静止，氛围定格。
```

## 必须强化的动作信息

- 发力链条：肩膀、腰部、手腕、翅膀、脚掌要有明确先后关系。
- 道具轨迹：飞刀、手里剑、篮球、水环等必须写出方向、速度、旋转、拖影、气流或冲击。
- 受力反馈：起跳、转体、落地、膝盖卸力、衣摆晃动、发丝受气流影响。
- 剪辑节奏：需要硬切就明确写“硬切”，不要让模型做缓慢渐变或漂移过渡。
- 特写目的：特写必须服务表情、眼神、张嘴喊话或情绪升级。
- 台词顺序：有台词时严格写清“一人一句交替”，并保留原台词。

## 禁止模糊写法

- 不写“角色躲开攻击”这种抽象句，要写清楚怎样蹬地、转体、侧闪、落地。
- 不写“飞刀飞过去”就结束，要写清楚脱手、旋转、拖影、方向和落点。
- 不写“镜头切换很快”就结束，要写清楚切到谁的近景、表情是什么、说哪句台词。
- 不让角色无过程瞬移到尾帧，摔倒、后退、飞行、爆炸都必须有过程。

## 适合直接套用的模板

```text
0-1.5s｜中景固定镜头，打斗动态表演：{角色A}肩膀/腰部带动短翅蓄力，手腕或翅尖猛然甩出，{道具}脱手弹射；{道具}高速自旋，刀刃或主体带锐利运动拖影，空气产生微弱气流残影，飞行轨迹明确朝向{角色B}；{角色B}脚掌蹬地起跳，腰部快速扭转，完成侧身转体闪避，避开弹道；双脚轻巧落地，膝盖微屈卸力，发丝与衣摆被气流带动，最后稳住。

1.5-3s｜硬切剪辑，快速切至{角色B}脸部近景特写，轻微面部跟焦，眼睛睁大、嘴巴张开，高声喊出：“{台词B1}”；硬切到{角色A}脸部近景特写，眼神锐利、下颌发力，张嘴回应：“{台词A1}”。严格一人一句交替。

3-4.5s｜继续硬切近景，{角色B}情绪进一步高涨，大声喊：“{台词B2}”；立刻硬切到{角色A}，气场强化，放声大喊：“{台词A2}”。人物交替出镜，不插入无关镜头。

4.5-6s｜平稳切回双人全景，两人保持战斗起手姿态，互相直视，身体完全静止，形成剑拔弩张的对峙定格。

整体风格：{项目指定画风}，动作物理流畅，发力、起跳、落地、卸力细节完整；高速运动物体施加动态模糊；硬切剪辑，不要缓慢渐变转场；严格遵循时间轴，台词严格交替一人一句。
```
