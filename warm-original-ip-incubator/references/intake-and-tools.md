## 参数收集表单

调用 `generate_form_for_info_collection` 时，一次性包含下列字段：

| 字段 | 必填 | 预设选项或说明 | 缺失时处理 |
|---|---:|---|---|
| 目标受众 | 是 | 女生、亲子、年轻打工人、治愈系观众、品牌用户、自定义 | 提示用户补充 |
| 情绪方向 | 是 | 治愈、温暖、孤独陪伴、可爱搞笑、慢生活、睡前安抚 | 提示用户补充 |
| 角色类型 | 是 | 小动物、植物、食物、天气精灵、生活物件、抽象情绪体 | 提示用户补充 |
| 使用场景 | 是 | 短视频、表情包、品牌吉祥物、绘本、头像、商品包装 | 提示用户补充 |
| 是否有参考图或草图 | 是 | 上传草图、上传参考图、已有候选图、无 | 有图则优先走 `image2image` |
| 视觉风格 | 否 | 毛绒、软陶、黏土、3D、手绘、水彩、定格动画 | 默认毛绒/软陶治愈风 |
| 材质偏好 | 否 | 毛绒、软陶、棉花、果冻、苔藓、木头、云朵、自定义 | 默认依据角色类型选择一种主材质 |
| 色彩偏好 | 否 | 暖色、低饱和、森林色、奶油色、季节色、自定义 | 默认低饱和暖色 |
| 世界观偏好 | 否 | 森林厨房、雨后便利店、云朵车站、月光面包房、自定义 | 默认微缩自然生活空间 |
| 商业用途 | 否 | 无、品牌吉祥物、授权商品、包装、电商内容、自定义 | 默认先按内容 IP 设计 |
| 禁止方向 | 否 | 不像某知名 IP、不要恐怖、不要太幼稚、不要商业吉祥物感、自定义 | 默认避开知名 IP 仿作 |

允许多选的字段应尽量设置为多选；“自定义”应允许自由文本补充。表单标题使用“温馨原创 IP 孵化偏好”，说明填写时间约 1–2 分钟。

## 默认值与补问规则

- 不重复询问用户已在对话中说明的信息，预填到表单或直接记录。
- 必填项缺失时，只补问缺失项；不要重新发送整套问题。
- 可选项缺失时使用表中默认值，并在“结构化 IP 孵化输入”中标注“采用默认”。
- 用户说“你决定”或“直接做”时，允许采用所有默认值并继续。
- 用户提供参考图但当前无法访问时，请用户重新上传或提供可访问路径；不得假装看过图片。

## 三个无方向起点

用户完全没有想法时，先给 3 个可选择的起点，再展示表单。每次应结合用户场景重新生成，不要机械复用。起点至少在角色母题和世界观上不同，例如：

1. 天气精灵：认真慢半拍的小雨滴，在雨后便利店替大家收好湿云朵。
2. 食物角色：怕冷的小面包团，在月光面包房守着一盏发酵灯。
3. 生活物件：总想帮忙的小袜子，在森林洗衣房寻找走散的另一只。

这些只是启发方向，不是固定答案。

## 工具路由

| 用户状态或请求 | 工具 | 关键要求 |
|---|---|---|
| 初次孵化、偏好不完整 | `generate_form_for_info_collection` | 一次性收集，避免逐题追问 |
| 无参考图，想看首版角色 | `text2image` | 生成 3 张差异化候选图 |
| 有草图、参考图或已选图 | `image2image` | 保持核心特征，局部延展 |
| 想看角色动起来 | `multi_modal2video` | 使用主角色图，动作短且清晰 |
| 查询进度、继续编辑已有任务 | `get_resource_status` | 先确认资源状态，再编辑 |

工具调用失败时，保留已形成的设定与 Prompt，说明失败点和可重试项，不要从头推翻方案。
