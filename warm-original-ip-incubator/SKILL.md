# 温馨原创 IP 孵化

## 核心目标

设计一个让人愿意记住、愿意看下去、能持续产出内容的原创角色。优先保障视觉记忆点、情绪吸引力、生活世界观和系列化能力，不止追求单张图好看。

全程使用中文与用户协作，除非用户要求其他语言。保持建议具体、可执行，避免只写“可爱、治愈、萌”等空泛词。

## 开始前

1. 读取 [references/intake-and-tools.md](references/intake-and-tools.md)，按其中字段一次性收集偏好并遵守工具路由。
2. 设计概念、生成角色卡或做最终检查时，读取 [references/design-and-output-spec.md](references/design-and-output-spec.md)。
3. 识别当前阶段，不要求用户重复已经提供的信息。
4. 若用户已有角色图或草图，保留其核心特征，在原有基础上提炼钩子，不推翻重做。
5. 若用户点名模仿知名 IP，将其转换为抽象特征需求，例如气质、材质、叙事节奏或配色倾向；不得复刻轮廓、五官、服饰、道具组合或标志性设定。

## 阶段控制

按 Phase 1–5 推进。每个阶段只索取进入下一阶段所需的最少确认；用户明确授权“直接完成”时，可基于合理默认值连续完成，并清楚标注假设。

### Phase 1：收集创作意图

进入条件：用户表达想孵化、设计或优化治愈系原创 IP。

执行：

1. 调用 `generate_form_for_info_collection`，一次性收集目标受众、情绪方向、角色类型、使用场景、视觉偏好、世界观与禁区。
2. 必填项为目标受众、情绪方向、角色类型、主要使用场景、是否有参考图或草图。
3. 用户没有明确方向时，在表单前提供 3 个差异明显的起点，每个用一句话说明角色母题、情绪与世界观。
4. 将结果整理为“结构化 IP 孵化输入”，区分用户明确提供的信息与采用的默认值。
5. 信息足够时直接进入 Phase 2；缺少必填项时只补问缺失项。

产物：结构化 IP 孵化输入。

### Phase 2：设计 IP 核心钩子

进入条件：已获得足够偏好。

执行：

1. 生成 3 个彼此明显不同的原创概念方向。
2. 每个方向必须包含：一句话记忆点、外形轮廓、情绪钩子、标志动作、标志道具、生活世界观、可持续栏目方向。
3. 用 1–5 分评估记忆度、治愈感、系列化潜力、生成稳定性；“生成难度”另标为低/中/高并解释最主要风险。
4. 推荐 1 个最适合用户目标的方向，说明选择依据和需要规避的相似性风险。
5. 等待用户选择、混合或修改方向。若用户已授权直接完成，采用推荐方向继续。

产物：3 个概念方向与 1 个推荐方向。

### Phase 3：生成角色设定卡

进入条件：用户确认方向，或已授权采用推荐方向。

执行：

1. 用七维设计法完善角色：轮廓、情绪、材质、动作、道具、世界观、栏目化能力。
2. 为角色设置一个可亲近的性格缺陷或小习惯，使其能自然制造微小冲突和剧情。
3. 锁定 3–5 个不可变的核心视觉特征；其余服饰、表情和季节元素作为可变层。
4. 说明角色适合反复出现的生活场景，并验证至少可扩展 30 条内容。
5. 按 [references/design-and-output-spec.md](references/design-and-output-spec.md) 的模板生成 Markdown 角色设定卡。若可写入用户项目，保存为 `IP角色设定卡-<角色名>.md`；否则在回复中输出完整 Markdown。
6. 询问是否进入视觉生成阶段；用户仅需设定卡时在此结束。

产物：完整的 Markdown 角色设定卡。

### Phase 4：生成视觉 Prompt 与候选图

进入条件：用户明确希望生成角色视觉。

执行：

1. 按规定顺序编写即梦角色 Prompt：原创身份 → 轮廓 → 材质 → 表情与性格 → 动作/道具 → 世界观 → 画面风格 → 限制项。
2. 没有参考图时调用 `text2image` 生成 3 张候选图，分别偏向：
   - 更软萌；
   - 更有轮廓记忆点；
   - 更适合短视频系列与动作一致性。
3. 有草图、参考角色或已选候选图时调用 `image2image`，保持核心轮廓和不可变特征，优化造型、材质、服饰、表情或场景。
4. 清楚标记每张候选图的设计差异和生成稳定性风险，不只说“版本 A/B/C”。
5. 用户选定主角色后，输出可复用的“角色一致性 Prompt”，包含不可变特征、允许变化项、镜头/材质规则与负面限制。
6. 用户要求角色动作测试时，以主角色图为参考调用 `multi_modal2video` 生成短动作片段。

产物：3 张差异化候选图、选择建议、即梦角色 Prompt、角色一致性 Prompt；需要时附动作测试。

### Phase 5：规划系列化内容

进入条件：角色核心设定已确认。

执行：

1. 输出首批 10 条短视频选题，每条包含栏目类型、场景、动作、情绪、可视化亮点。
2. 至少覆盖以下类别中的 3 类：生活日常、美食治愈、节气/季节、轻旅行、睡前陪伴、节日限定。
3. 让固定动作、固定道具或固定场所反复出现，形成角色识别资产。
4. 选出最适合先做的 3 条 MVP，说明其制作简单度、角色辨识度和连载潜力。
5. 询问用户是否将某条选题继续转为“原创 IP 治愈生活短片生成”Skill 的输入。
6. 将最终内容回填到同一份 Markdown 角色设定卡，严格保持规定标题顺序。

产物：首批 10 条短视频栏目表、3 条 MVP、可交接给后续视频 Skill 的角色资产包。

## 工具规则

- 偏好收集：`generate_form_for_info_collection`
- 无参考图的首版视觉：`text2image`
- 有草图、参考图或已选图的延展：`image2image`
- 角色动作测试：`multi_modal2video`
- 查询生成进度或在二次编辑前确认资源状态：`get_resource_status`

调用任何生成工具前先遵循其当前参数 schema。工具未暴露时，先通过可用的工具发现机制查找；确认不可用后，明确说明限制并交付可直接复制的 Prompt，绝不伪造任务 ID、进度、图片或视频结果。

## 全局约束

- 只设计原创角色，禁止复刻或近似模仿已有知名 IP。
- 不生成低俗、恐怖、畸形、侵权或不适合公开发布的设定。
- 控制造型复杂度：核心轮廓清晰，纹样、配件和颜色数量适合跨镜头稳定生成。
- 优先考虑一句话记忆点和至少 30 条内容的系列化潜力。
- 任何关键质量项不足时，先指出具体问题，再给出可直接替换的优化方案。
- 最终资产包必须能直接供即梦图像生成和后续“原创 IP 治愈生活短片生成”Skill 使用。
