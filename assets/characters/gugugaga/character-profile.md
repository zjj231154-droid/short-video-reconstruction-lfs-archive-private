# IP 角色设定卡：咕咕嘎嘎

## 角色名

咕咕嘎嘎

## 一句话记忆点

脖子上挂着巨型金属拉链的软萌企鹅修理工，看起来冷酷实则手忙脚乱总想帮大家修东西。

## 适合受众

年轻打工人、二次元手办爱好者、治愈系短视频观众、潮玩收藏家

## 外形轮廓

圆滚滚 Q 版企鹅身体，黑色企鹅头套露出发梢，剪影辨识度极强，短粗小翅膀 + 黄色鸭掌，全身轮廓圆润没有锐角，缩小后也能一眼认出。

## 材质与触感

哑光软陶黏土质感，表面细腻光滑，像 Nendoroid 潮玩手办，身体摸起来冰冰凉凉，腹部留白部分像雪一样软，金属拉链项圈带着细微的冷金属反光质感。

## 颜色系统

主色：炭黑 + 米白 + 鹅黄\
点缀色：枪灰色金属 + 一点点红色拉链锁色块\
整体配色克制高级，低饱和治愈感。

## 性格设定

嘴上不怎么说话，行动比脑子快，看到什么东西坏了就忍不住伸手去拧两下螺丝刀。动手能力时灵时不灵，经常把修好的东西又搞出新问题，最后蹲在旁边不好意思地挠头。生活里是路痴，出门买螺丝经常迷路半天才能回家。

## 情绪钩子

想帮忙但总把事搞砸，蹲在零件堆里一脸愧疚又想下一次再试的笨拙感，让人忍不住想摸摸头。

## 标志动作

举起两只短翅膀比加油，蹲在地上拆手里的小螺丝，抱着比自己还大的扳手歪头看镜头。

## 标志道具

脖子上永远挂着的巨型金属拉链，口袋里掉出来的迷你螺丝刀，脚边永远放着一个印着小企鹅图案的铁皮工具箱。

## 生活世界观

住在城市边缘老工厂的半废弃工具间里，阳光从破玻璃窗斜照进来，满地都是乱七八糟的旧零件和没拼完的小发明。旁边就是草地和芦苇荡，休息的时候就拉着粉粉去草地上躺平看云。

## 内容栏目方向

1. 小企修理日记：修坏各种可爱小物件的翻车日常
2. 企鹅打工记：去不同店铺做临时工的笨笨体验
3. 两个企鹅的治愈周末：和粉粉一起野餐、逛旧货市场、散步发呆
4. 手办开箱记录：拆快递新到的工具和零件
5. 冬日南极访客系列：偶尔幻想自己回到南极老家的脑洞故事
