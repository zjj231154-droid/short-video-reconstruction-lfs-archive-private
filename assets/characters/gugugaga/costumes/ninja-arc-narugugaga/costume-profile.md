# 咕咕嘎嘎忍者篇服装设定：纳鲁咕嘎

## 资产定位

本目录是咕咕嘎嘎在“忍者篇／忍道之争”中的服装变体，不替代
`../../turnaround/` 内的标准角色三视图。后续生成忍者篇分镜或视频时，
必须同时加载标准三视图与本目录的服装三视图。

## 身份锁定

- 保留黑色企鹅头套、白色眼部标记和黄色鸟喙。
- 保留黑色短发、金属发夹、灰蓝大眼睛。
- 保留圆胖黑白企鹅身体、白色腹部、黄色脚掌和背部企鹅尾巴。
- 保留巨型金属拉链项圈；正面大拉链头、背面拉链结构均不可删除。
- 保持哑光软陶／黏土手办质感和矮胖 Q 版比例。

## 忍者服装

- 白色短款忍者羽织，衣襟敞开，露出白色腹部。
- 高黑领围绕巨型拉链项圈适配，不遮挡拉链识别点。
- 袖口与衣摆为红橙渐变火焰纹，火焰数量和位置保持简洁稳定。
- 黑色护额带包住企鹅头套，银色铆钉金属片中央为黑色空心三角徽记。
- 背部竖排黑字“十代”，仅出现一次。

## 一致性 Prompt

咕咕嘎嘎“纳鲁咕嘎”忍者篇服装变体。严格保持标准角色的黑色企鹅头套、
白色眼部标记、黄色鸟喙、黑色短发与金属发夹、圆胖黑白企鹅身体、白色腹部、
黄色脚掌、企鹅尾巴和巨型金属拉链项圈。穿白色短款忍者羽织，袖口与衣摆为
红橙火焰纹，背部竖排“十代”；戴黑色布质护额，银色铆钉金属片中央为黑色
空心三角徽记。哑光软陶手办质感，Q 版矮胖比例。不得改成人类体型，不得删除
或缩小巨型拉链，不得替换企鹅头套、黄色鸟喙、发夹、黄色脚掌和背部尾巴。
