# 角色设定图版式与规格

设定图是一张**综合排版图**，把主形象、多角度/多表情、服装道具特写和色标卡放在同一画面，便于分镜与后期统一角色造型。

## 布局建议

- **中央**：主形象大图（全身或半身，标准站姿或常见姿态）。
- **顶部或一侧**：多角度小图（正面、侧面、背面）或多表情小图（常态、微笑、冷厉等）。
- **底部**：一排服装或道具特写（衣纹、佩剑、发簪、纹样等）。
- **右侧或底部**：色标卡（主色、辅助色、点缀色，带 HEX 或描述）。

实际排版可按比例调整，保持「主形象突出、其余为参考」即可。

## 主形象

- 一张完整角色图，包含：全身或半身、标准/常见姿态、服装与主要道具清晰可见。
- 风格与描述词中的「画风」一致，与场景设定图统一（如国风动漫CG风）。
- 构图稳定，便于作为成片角色造型主参考。

## 多角度 / 多表情

| 类型 | 内容 | 用途 |
|------|------|------|
| 多角度 | 正面、侧面、背面 | 不同机位下的造型参考 |
| 多表情 | 常态、关键情绪（如冷厉、温柔、决绝） | 分镜表情与弧光参考 |

同一角色、同一服装与画风，仅角度或表情不同。可按剧本只出需要的角度或表情。

## 服装 / 道具特写

- 选 3–5 类关键细节：衣领/衣摆纹样、佩剑/法器、发簪/头饰、标志性配件。
- 用于成片中的特写镜头与材质参考，保证与主形象一致。

## 色标卡

- **主色**：角色服装/头发的主色（如青、绯红、月白）。
- **辅助色**：次要服装、肤色、阴影。
- **点缀色**：配饰、武器光效、高光（如银纹、淡金灵光）。
- 尽量提供 HEX 或可复现描述，便于后期统一角色配色。

## 与生成流程配合

1. 用角色描述词生成**主形象**大图。
2. 在同一描述词基础上追加「正面/侧面/背面」或「常态/冷厉/温柔」等生成多张。
3. 用局部描述（如「衣摆银纹特写」「剑身与剑柄特写」）生成特写图。
4. 从主图或设定中提取色板，整理成色标卡。
5. 将以上拼成一张设定图（可用 Figma/PS/PPT 等），或分块输出供分镜直接引用。

## 与场景设定图的关系

- 角色设定图与场景设定图应**画风一致**（如均为国风动漫CG风）。
- 色标卡可与场景色标共用主色系，点缀色可区分角色（如不同角色不同 accent 色）。
