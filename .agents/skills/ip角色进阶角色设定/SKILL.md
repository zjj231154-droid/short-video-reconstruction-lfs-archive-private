# AI 漫剧角色设定

根据剧本角色表（如「角色设定.md」）或角色描述，产出**角色描述词**与**角色设定图规格**，供选角、分镜与成片使用。设定图为多维度视觉参考（主形象、多角度/多表情、服装道具特写、色标卡）。

## 本项目既有角色优先规则

本技能已按当前项目做最小适配。使用时必须同时遵守项目根目录
`AGENTS.md` 的角色一致性规则：

- DORO（粉粉）和咕咕嘎嘎（小企）属于已有权威角色，只能在原设定上深化，
  不得按通用人类角色模板重新设计。
- 处理这两位角色前，先读取对应 `assets/characters/<id>/character-profile.md`，
  并同时参考 `turnaround/front.png`、`side.png`、`back.png`。
- 工具支持图片参考时必须附带三视图；两位角色同框时加载两套人设和全部六张三视图。
- 新增服装、表情、声音、道具或剧情弧光时，保留角色的不可变轮廓、配色、
  材质、标志配件与 Q 版比例。
- 新创建的其他角色可按本技能下方的通用工作流执行。

- 从角色设定文档中抽取单角做视觉/听觉设定
- 需要与场景画风统一的角色参考图

## 角色描述词结构

描述词按固定维度组织，便于模型稳定出图与后续修图，并与剧本角色表一一对应：

| 维度 | 说明 | 示例 |
|------|------|------|
| **画风** | 与场景统一 | 电影级写实 3D 真人 CG、治愈软陶 3D |
| **年龄** | 具体或范围 | 十八岁上下、五十岁上下 |
| **性别** | 男性/女性/男女皆有（群像） | 男性、女性 |
| **身高** | 可选范围 | 161cm、178cm、191cm |
| **体型** | 身材特征 | 高大宽厚、精瘦结实、匀称紧实、Q 版圆润 |
| **脸型** | 轮廓 | 骨骼硬朗、柔和椭圆、非人形原始轮廓 |
| **五官/气质** | 相貌与神态，可含前后期变化 | 沉着警觉、理性坚定、热烈坦率、克制疏离 |
| **发型与配饰** | 发型、头饰、标志物 | 发色与长度、护额、发夹、蝴蝶结等固定识别物 |
| **服装** | 上衣、下装、外搭、纹样 | 剪裁、层次、材质、纹章与磨损状态 |
| **道具/武器** | 手持或佩带 | 卷轴、忍具包、佩剑或角色专属生活道具 |
| **声音设定** | 音高、音色、语速、特点 | 中低音、胸腔共鸣、语速从容；中高音、明亮有颗粒感 |

### 提示词格式

```text
{角色名}{ 通用形象}角色描述词: 画风，年龄，性别，身高，体型，脸型，五官（可含前期/后期），发型与配饰；服装，道具。角色声音设定: 前期…（音高、音色、特点），后期…（音高、音色、特点）。
```

「通用形象」仅群像/路人角色使用；单人主配角不写。声音设定若无前后期变化可只写一段。

### 示例一：从角色总设定提取单角

先读取 [火影忍者五人群像角色设定.md](references/角色/火影忍者五人群像角色设定.md)，
定位目标角色的小节，再按上方固定格式抽取角色描述词。生成或修改设定图时，同时引用
`references/角色/三视图/` 中同名 PNG，保持脸型、发型、服装、身高和标志物一致。

### 示例二：设定图版式提示词（角色描述 + 布局）

用于一次性生成整张角色设定图时，在角色描述前加上**版式与布局**说明：

```text
【版式】一张 AI 漫剧角色设定图，网格排版，包含：中央为主形象（全身或半身）；顶部或一侧为同一角色的正面、侧面、背面；底部一排为面部、服装、道具和标志物特写；右侧或底部为色标卡（主色、辅助色、点缀色，附 HEX）。【角色】{按角色描述词固定格式填写，并附对应权威三视图作为图像参考}
```

更多模板与变体见 [references/prompt-template.md](references/prompt-template.md)。

## 角色设定图规格

设定图是一张**综合排版图**，包含以下区块，为分镜与后期提供统一参考：

| 区块 | 内容 | 用途 |
|------|------|------|
| **主形象** | 中央大图：全身或半身，标准站姿/常见姿态 | 成片角色造型参考 |
| **多角度/多表情** | 同一角色：正面、侧面、背面；或常态、关键表情 | 机位与表情参考 |
| **服装/道具特写** | 衣纹、配饰、武器、标志物 | 细节与材质参考 |
| **色标卡** | 主色、辅助色、点缀色（含 HEX 或描述） | 配色与后期统一 |

布局建议：主形象居中，多角度/多表情在顶部或一侧，服装道具特写底部一排，色标卡在右侧或底部。

详细版式见 [references/setting-image-spec.md](references/setting-image-spec.md)。

## 工作流

1. **输入**：角色设定表（如「角色设定.md」中单条）、或用户口头描述。
2. **提炼**：从「身份」「外貌/气质」「性格」「弧光」中抽取年龄、体型、五官气质、服装风格、前后期变化。
3. **写描述词**：按格式填写画风、年龄、性别、身高、体型、脸型、五官、发型服装道具、声音设定。
4. **写设定图需求**：说明主形象 + 多角度/多表情 + 服装道具特写 + 色标卡；有指定表情或角度时写明。
5. **输出**：
   - 角色描述词（可直接用于文生图）
   - 设定图规格说明（用于生成或外包设定图）

## 与其它技能配合

- 场景设计：角色与场景共用同一画风（如国风动漫CG风），便于成片统一。
- 文生图：用本技能产出的描述词生成单张立绘，或分批生成多角度/多表情/特写，再拼成设定图。
- 漫画分镜：用设定图的主形象与色标做角色造型与配色参考。

## 输出示例

**角色描述词**：单张立绘使用固定格式；整张设定图使用含版式描述的格式。

**设定图需求摘要**：

- 主形象：目标角色全身，标准站姿，核心服装与标志道具清晰。
- 多角度/多表情：正面、侧面、背面；常态与关键情绪。
- 特写：面部识别点、服装材质、核心配件与道具。
- 色标：主色、辅助色、点缀色，附 HEX。

完整群像设定见 [火影忍者五人群像角色设定.md](references/角色/火影忍者五人群像角色设定.md)，
对应设定板见 [references/角色/三视图/](references/角色/三视图/)。
