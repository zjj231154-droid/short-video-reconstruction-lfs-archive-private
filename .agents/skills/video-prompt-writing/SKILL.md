# 视频提示词编写

将用户的场景、剧本片段、分镜描述或参考素材，转换成可直接用于 Seedance 2.x 或 Higgsfield Seedance 的制作级英文视频提示词。

## 使用流程

1. 读取当前项目根目录的 `AGENTS.md`，将项目规则置于本技能和通用电影方法之上。
2. 阅读 [CINEDANCE / Higgsfield 方法论](references/cinedance-higgsfield.md)；按其中的 4-D 流程、空间控制、光学控制、物理与连续性规则工作。
3. 只提取当前镜头或当前序列真正会出现、发生或被听到的内容。移除场次号、旧镜头残留、未使用角色和无效引用。
4. 明确活动角色、参考素材、地点、道具、时长、画幅、首帧、空间位置、视线、身体朝向、动作、镜头、光线、物理和声音。
5. 默认选择单一连续镜头；只有用户明确要求剪辑，或单镜头无法清楚呈现信息时，才使用受控多镜头结构。
6. 先锁定空间与首帧，再选择视场角和摄影机行为，随后编排动作时序、物理、光线和音频。
7. 静默完成方法论中的自检并修正问题，再输出最终提示词。

## 项目角色一致性

当提示词包含 DORO（粉粉）或咕咕嘎嘎（小企）时，必须遵守项目 `AGENTS.md`：

- 读取对应 `assets/characters/<角色>/character-profile.md`。
- 同时检查正面、侧面、背面三张 `turnaround/` 图；使用图像查看工具确认视觉特征。
- 动作、表情或服装接近既有素材时，追加查看最相关的 `expression-action-references/` 或服装资产。
- 两位角色同框时，读取两份人设并检查全部六张三视图。
- 将核心识别特征压缩成少量强约束，避免用冗长描述覆盖权威参考。
- 用户要求与权威设定冲突时，先指出冲突并征得确认。

## 输入处理

- 保留用户明确指定的剧情、对白、旁白、画面比例、时长和镜头要求。
- 缺少非关键细节时，做符合场景的保守假设并继续；只有会显著改变剧情或制作方案时才询问。
- 不虚构 `@tag`。仅保留用户或平台已经提供、且当前镜头实际使用的引用标签。
- 平台 UI 已控制的模型、分辨率、帧率、画幅和时长默认不重复写入提示词，除非它们影响画面或用户要求写入。

## 输出规则

- 默认只输出最终英文视频提示词，不附分析、QA、改写说明或方法论。
- 用户明确要求中文、双语、多个方案、解释或诊断时，按要求输出。
- 按需使用这些段落，不机械补齐空段：`SCENE CONTEXT`、`ACTIVE REFERENCES`、`LOCATION MAP`、`FIRST FRAME AND SPATIAL BLOCKING`、`FORMAT MODE`、`OPTICS`、`CAMERA`、`ACTION TIMING`、`PHYSICS`、`LIGHTING`、`AUDIO`、`POSITIVE CONSTRAINTS`。
- 正向描述期望状态；仅对高概率失败点加入短小的局部禁止项。
- 对白只保留用户提供的台词；不增加即兴词、字幕、旁白或画外音。
- 使用具体、可见、可计量的语言，避免空泛诗意词和堆叠形容词。

## 最低质量门槛

输出前必须确认：

- 首帧包含所有必需主体，除非用户明确要求空镜开场。
- 角色左右、前中后景、距离、朝向和视线没有歧义。
- 参考身份、服装、道具、伤痕和环境状态跨镜头连续。
- 光学选择与镜头内容匹配，镜头内不发生无理由的视场漂移。
- 动作符合质量、重力、接触、惯性和时间长度。
- 主光方向、摄影机所在明暗侧和曝光优先级明确。
- 所有活动引用都被使用，且没有陈旧引用或上下文泄漏。
